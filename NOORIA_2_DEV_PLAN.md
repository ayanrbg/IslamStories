# Nooria 2.0 — план разработки

Nooria из библиотеки сказок превращается в приложение с ежедневными уроками для детей 3–8 лет. **Сказки остаются полностью**: они становятся вечерним режимом и наградой за уроки, и всё, что работает в них сейчас, должно работать и после.

Связанные документы:
- ТЗ уровня 1 (MVP): https://claude.ai/artifact/55aqHGMPEti8KpgGwv3UaK
- Обзор «как будет выглядеть приложение»: https://claude.ai/artifact/GnmyMqvDxZNypdTkekC3fU
- Референс Speech Blubs (скриншоты): Figma `3vpixCImvoNxsKuZSLXnKh`

Последнее обновление: 2026-11-23.

## Принятые решения

| Вопрос | Решение |
| --- | --- |
| Объём | Весь уровень 1, двумя релизами: сначала проверка формата на 3 уроках, потом полная версия |
| Ориентация | Уроки — горизонтально (как игры в Speech Blubs). Остальные экраны остаются в текущей ориентации приложения — она тоже горизонтальная, так что переключать не нужно |
| Маска в «Повтори как друг» | AR (face tracking). Запасные режимы — рамка с камерой и нарисованный персонаж |
| Видео друга | Реальные дети, письменные согласия родителей. Друг — нарисованный персонаж с лицом этого ребёнка |
| Фраза для повторения | Всегда арабская: одно видео на урок для всех языков |
| Микрофон | Запись голоса и сразу «послушай себя». Ничего не сохраняется |
| Аватар | Лицо ребёнка с фото на нарисованном теле или готовое нарисованное лицо. В релизе 1 также аватар мамы |
| Прогресс | Только на телефоне (`progress.json`), без серверного хранения |
| Языки уроков | ru, kz, en (en-US и en-GB — один текст). На остальных языках уроки скрыты |
| Платформа | Только Nooria (IslamStories). В Bala не переносим |
| Доступ | Бесплатно 1 сказка + 2 урока. В релизе 2 — анкета для родителя и 7 дней бесплатно |

## Сказки остаются

Сказки — вторая причина платить за подписку, поэтому ломать в них ничего нельзя.

**Остаётся без изменений:**
- библиотека сказок, карточки, деталь сказки, чтение, оглавление;
- имя и пол ребёнка в тексте, озвучка сервером, запись голоса мамы или папы и выбор голоса;
- бесплатная сказка `komar` (вшита в приложение), подарки, промокоды, рефералы, выдачи из админки;
- подписка, пейволл, восстановление покупок, SupportScreen после сказки (только в сказках);
- кеш сказок, обновление текста по contentVersion, работа без сети;
- push-уведомления, аналитика сказок.

**Что меняется вокруг сказок:**
- **Релиз 1:** в библиотеке сказок появляется блок «Урок дня» и вход в Дерево. Сама библиотека остаётся главным экраном.
- **Релиз 2:** библиотека становится вкладкой «Сказки» в нижней панели. Вечером приложение открывается на ней.
- **Релиз 2:** каждые 5 листков на Дереве открывают сказку. Бесплатному пользователю первая такая награда навсегда открывает одну платную сказку. Это локальная отметка, она учитывается в проверке замка сказки вместе с флагами сервера.
- Подписка открывает и сказки, и уроки. Тексты пейволла упоминают оба.

Регрессионная проверка сказок — в конце каждого релиза (чек-лист ниже).

## Этап 0. Подготовка

- [x] Проверить ориентацию. **Итог:** всё приложение уже горизонтальное. `defaultScreenOrientation: 3` (LandscapeLeft), автоповорот выключен, в собранном iOS 1.7.12 `UISupportedInterfaceOrientations` = только `LandscapeRight`. Числа 1080×1920 в CanvasScaler — это только опорное разрешение для масштабирования. Значит, переключать ориентацию при входе в урок не нужно (см. раздел 3 релиза 1).
- [x] `main` догнан до `android-minify-r8` (все ветки уже были в ней), ветка клиента `nooria-2-lessons` создана от `main`. Бэкенд — в ветке `wip`, на прод через `main` по обычной схеме деплоя.
- [x] Флаг `AppConfig.LessonsEnabled`: в Nooria `true`, в Bala `false` (добавлен в оба проекта). Все правки общих с Bala скриптов (библиотека, пейволл, навигация) закрыты этим флагом, чтобы общие файлы оставались одинаковыми в обоих проектах. Общие файлы не ссылаются на типы из `Lessons/` напрямую.
- [x] Новый код — в папке `Assets/Scripts/FairyTales/Lessons/`, её нет в Bala. Записано в списке различий близнецов в `AppConfig.cs` обоих проектов. Сама папка появится вместе с первым кодом.
- [x] Подключены AR Foundation, ARKit и ARCore 6.7.1 (только в Nooria). Face tracking в 6.x встроен в пакет ARKit, отдельного пакета нет. ARKit и ARCore — Optional, поэтому ARKit не попадает в `UIRequiredDeviceCapabilities`. «Initialize XR on Startup» выключен на всех платформах: AR запускается из кода только на шаге с маской. Пакеты подтянули Input System, но приложение осталось на старом Input Manager (`activeInputHandler: 0`), чтобы не трогать сказки.
- [x] AR-рендеринг. Сказки рендерятся URP **2D Renderer**, а фон камеры AR работает только с Universal Renderer. Поэтому добавлен второй рендерер `Assets/Settings/ARRenderer.asset` (индекс 1) с `ARBackgroundRendererFeature`. По умолчанию остаётся Renderer2D (индекс 0), AR-камера должна выбрать рендерер 1. Для Vulkan на Android в оба рендерера добавлен `ARCommandBufferSupportRendererFeature` (без запущенной AR-сессии он ничего не делает).
- [x] Базовый `NSCameraUsageDescription` (en). Переводы — в разделе 12.
- [ ] Замерить, насколько вырос размер сборки: сравнить AAB/IPA с 1.7.12.

## Релиз 1 — проверка формата

Цель: 3 урока внутри текущего приложения и ответ на вопрос, возвращаются ли дети к урокам чаще, чем к сказкам.

### 1. Бэкенд (Backend-Islam-Stories, ветка `wip`)
- [ ] Миграция: таблица уроков и тем (порядок, тема, free, статус, contentVersion, отметка «проверено имамом»).
- [ ] Файлы уроков: `data/lessons/<lang>/<id>.json`, медиа — `data/lessons-media/<id>/`.
- [ ] `GET /api/lessons?lang=` — темы и список уроков. Уроки без перевода на язык не отдаются.
- [ ] `GET /api/lessons/:id?lang=` — полный урок. Закрытый урок без подписки — 403 (через `services/entitlements.js`).
- [ ] `POST /api/lessons/:id/narrate` — озвучка всех текстов урока одним запросом (имя, пол, язык). Кеш по уроку, языку, contentVersion, имени, полу и голосу.
- [ ] Админ-API по образцу `routes/adminTales.js`: уроки и темы, загрузка JSON и медиа, публикация, порядок.
- [ ] `content-check`: медиа на месте, 3 варианта ответа и один верный, длина текстов, видео H.264 до 8 с и 3 МБ, есть отметка имама.
- [ ] Импорт из XLSX: `scripts/import-lessons-xlsx.js` по образцу `import-tales-xlsx.js`.
- [ ] Деплой на прод до выхода клиента. Старые клиенты новые эндпоинты не вызывают.

### 2. Основа клиента
- [ ] `LessonModels` — модели урока, шагов и медиа по формату из ТЗ (раздел 8). Неизвестный тип шага пропускается.
- [ ] `LessonService` — запросы к API через `ApiClient`.
- [ ] `LessonCache` — скачивание урока целиком до старта с прогрессом, обновление по contentVersion (как `ReconcileTextVersion`), фоновая докачка следующего урока по Wi-Fi.
- [ ] `LessonProgressStore` — `progress.json` в `persistentDataPath`: звёзды, листки, пройденные уроки, незаконченный урок и шаг, дела в ожидании отметки, серия дней. Запись через временный файл.
- [ ] Первый бесплатный урок вшит в `StreamingAssets/BundledLessons/` с заранее записанной озвучкой.

### 3. Плеер урока (горизонтально)
- [ ] Отдельный canvas плеера с горизонтальным референсом 1920×1080. Ориентацию переключать не нужно: приложение и так горизонтальное (этап 0).
- [ ] Каркас плеера: полоска из 5 сегментов, ✕ с подтверждением, продолжение с места выхода, «Назад» на Android работает как ✕.
- [ ] Шаг «История»: 1–3 страницы, иллюстрации для мальчика и девочки, текст через `TaleText` и `ShapedText`, озвучка, кнопка «Дальше».
- [ ] Шаг «Задание»: 3 карточки, перемешивание, мягкая реакция на ошибку, подсказка после двух ошибок.
- [ ] Шаг «Сделай в жизни»: аватары ребёнка и мамы, отметка через `ChildGatePopup`, «Готово» без отметки кладёт дело в ожидание.
- [ ] Шаг «Награда»: звезда и листок за первое прохождение, звезда за повтор не чаще раза в день.
- [ ] Общие озвученные фразы («Попробуй ещё», «Машаллах, правильно!», «Послушай себя!») вшиты для ru, kz, en.

### 4. Аватар ребёнка и мамы
- [ ] Экран создания аватара: фото камерой или из галереи, кадрирование лица в овал, 12 готовых нарисованных лиц.
- [ ] Наложение лица на нарисованное тело (мальчик или девочка), рендер в текстуру для использования в сценах.
- [ ] Аватар мамы — тот же экран.
- [ ] Фото хранятся только локально. Добавление — через родительский замок, перед камерой текст о хранении.
- [ ] Где показывается: блок «Урок дня», сцена с другом, «Сделай в жизни», награда, Дерево.

### 5. «Повтори как друг» без AR
- [ ] Сцена с другом: аватар ребёнка и друг (нарисованное тело с лицом ребёнка из видео) стоят рядом, друг поднимает руку, в облачке фраза.
- [ ] Видео друга через `VideoPlayer` из кеша.
- [ ] Микрофон через `MicRecorder`: автоматическое прослушивание до 5 с, поиск голоса по порогу над шумом, конец записи после 0,8 с тишины, сразу проигрывание записи. Запись только в памяти.
- [ ] Два «тихих» раза подряд — кнопка «Дальше» с похвалой. Без микрофона — кнопка «Я сказал(а)!».
- [ ] Режим «Рамка»: фронтальная камера через `WebCamTexture`, плоские наклейки маски.
- [ ] Режим «Персонаж»: аватар в маске, рот двигается от громкости.
- [ ] Экран разрешений для родителя (камера и микрофон) с вариантом «Без камеры».

### 6. AR-маска
- [ ] AR-сессия с фронтальной камерой только на этом шаге, остановка при выходе и сворачивании.
- [ ] Три маски (корона с полумесяцем, фонарик-фанус, звёзды), переключатель масок.
- [ ] Выбор режима: AR, если поддерживается и сессия стартовала за 3 с, иначе рамка, без камеры — персонаж.
- [ ] Проверка: 2 дешёвых Android, iPhone без TrueDepth, iPhone с TrueDepth.

### 7. Входы, звёзды, Дерево
- [ ] Блок «Урок дня» в библиотеке сказок (за флагом `LessonsEnabled`): первый непройденный урок, замок на закрытых.
- [ ] Счётчики звёзд и серии дней.
- [ ] Простое Дерево: одно дерево, листки на фиксированных местах, список листков.

### 8. Доступ и монетизация
- [ ] Флаг `free` у уроков с сервера. Замок урока — та же логика, что `TaleSummary.IsLocked`.
- [ ] Пейволл из урока через родительский замок, текст «Все уроки и сказки, Дерево добрых дел, прогресс ребёнка».
- [ ] После награды за второй бесплатный урок — мягкое предложение подписки с кнопкой «Позже».
- [ ] SupportScreen в уроках не показывать.

### 9. Аналитика
- [ ] События: `lesson_open`, `lesson_download`, `lesson_step`, `lesson_exit`, `lesson_complete`, `repeat_attempt`, `camera_permission`, `mic_permission`, `ar_support`, `quiz_answer`, `deed_marked`, `tree_open`, `paywall_open` с источником, `avatar_created`.
- [ ] Отчёт для эксперимента на зеркале событий: возврат на 1-й и 7-й день у прошедших урок против читавших только сказки.

### 10. Локализация
- [ ] Тексты интерфейса уроков на ru, kz, en.
- [ ] На остальных 9 языках блок уроков и Дерево скрыты, приложение работает как раньше.

### 11. Контент (параллельно с разработкой)
- [ ] 3 урока: Бисмиллях, Приветствие, Благодарность (бесплатные — первые два) на ru, kz, en.
- [ ] 3 видео с детьми, фото их лиц для персонажей-друзей, согласия родителей.
- [ ] Иллюстрации историй и заданий, тела аватаров и 12 лиц, 3 маски (AR и плоские), Дерево.

### 12. Проверка и магазины
- [ ] Без сети, с запрещёнными камерой и микрофоном, на слабых Android, на всех 12 языках.
- [ ] Регрессия сказок по чек-листу ниже.
- [ ] `NSCameraUsageDescription` на всех языках, дополнить `NSMicrophoneUsageDescription`, разрешение `CAMERA` на Android.

## Релиз 2 — полная версия

- [ ] **Навигация:** нижняя панель Учимся · Дерево · Сказки · Родителям. Вкладка «Сказки» — текущая библиотека.
- [ ] **Главная «Учимся»:** приветствие, «Урок дня», темы-пузыри с сервера.
- [ ] **День и вечер:** днём открывается «Учимся», вечером «Сказки» (с 18:00, родитель может сдвинуть). Тёмная тема и тихие звуки вечером.
- [ ] **Сказка в награду:** каждые 5 листков — сказка. Бесплатному пользователю первая награда навсегда открывает одну платную сказку.
- [ ] **Дерево:** 5 стадий роста, листки за добрые дела, анимация нового листка.
- [ ] **Раздел «Родителям»:** итоги, темы и привычки, «Ждут отметки», добавить доброе дело (10 пунктов с сервера, до 3 в день), настройки камеры, микрофона и времени вечера, подписка, имя и язык, голоса для сказок, удаление фото.
- [ ] **Семья в аватарах:** папа, бабушка, дедушка, брат, сестра. Задание «с папой» показывает папу.
- [ ] **Новые виды заданий:** обвести по контуру (после обводки предмет раскрашивается), собрать пазл из 2–4 частей.
- [ ] **Анкета для родителя:** имя, пол и возраст, аватары, что ребёнок уже знает, важные ценности, минуты в день и время, экран «План для Айши», пейволл с пробным периодом 7 дней. Без «оценок развития».
- [ ] **Пробный период:** вводное предложение на 7 дней в App Store и Google Play для текущих подписок.
- [ ] **Контент:** оставшиеся 7 уроков, дальше 2–4 урока в месяц.
- [ ] Регрессия сказок по чек-листу ниже.
